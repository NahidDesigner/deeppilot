# Code of Conduct

DeepPilot follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind, be patient, and assume good intent. People here come from many countries and speak English at every level, so help each other understand rather than correcting each other. Harassment, insults and personal attacks aren't tolerated.

To report unacceptable behaviour, contact the maintainer privately through GitHub ([@NahidDesigner](https://github.com/NahidDesigner)). All reports are handled confidentially.
